## 当前交付

上方画布、下方操作面板及可拖动分隔条；普通单击房间或目录进入，移动房间时可用明确的“进入房间编辑”。实例独立放在“元素”页；点平台、怪物或机关直接打开属性并定位到可操作尺度，“整房”返回总览。拖动与改尺寸显式分开，指针抬起提交最终位置，房间占地不会随实例拖动改变。新增实例落在实际腔体内，避免凹形房的包围盒中心空白。

真实设备报错 `couldnt retrieve remote JWK set, read time out` 对应身份签名公钥下载超时。ChatGPTAuth为唯一协议所有者，PlanAuth只适配Android浏览器和返回前台。客户端身份在交换前保存；浏览器及时确认收到回调并返回App展示进度。交换后的待核验凭据加密保存，公钥暂不可用可直接“重试身份核验”，不重用授权码或重新注册，不以跳过验签换登录成功。取消覆盖网络请求并阻止迟到响应激活会话；错误只暴露安全阶段码和服务请求ID。旧版失败时已丢弃的凭据无法恢复，更新后需要重新连接一次。

AI在明确范围内校验后直接更新草稿，支持停止、差异及任务撤销；必要邻房只联动关联门对。账号和模型在启动／前台恢复；回调收到、身份验证、模型可用与真实推理区分。世界规划拓扑、森林24房候选蓝图与已校准空间分别展示，不把265间未定位房伪装成真实腔体。只支持当前格式；用户更新前自行导出，不转换或合并旧草稿。当前任务撤销、人工锁定和正式PR并发保护保留。

## 实际验证

36项Node测试、前端生产构建、21项Android单元测试与签名Release APK构建通过。13项授权协议测试使用真实本地HTTP服务、回调及RSA签名，覆盖公钥超时后恢复／跨实例重试、客户端身份复用、签名与声明拒绝、取消和迟到响应、重复回调参数、发现地址校验、刷新令牌轮换与原身份保护；其余8项验证模型目录和响应流。

Chromium390×844触摸操作覆盖单击进房、点实例打开属性、修改宽度与触摸拖动只改实例；授权界面验证身份重试不再发起授权以及重启恢复。桌面及分类／元素专项检查通过。浏览器授权与试玩使用模拟原生桥接，媒体有明确标注；不能据此声称Android真机或真实ChatGPT账号成功。Java/OkHttp＋Nimbus实测官方发现与公钥端点HTTP200、读取4把公钥；未使用用户账号，未执行真实AI编辑。

APK内前端逐文件与当前构建一致；数据及运行包schema3和行为哈希一致，PCK摘要未变，签名沿用原证书。配套游戏验证沿用PR157的43正式房／44可编辑场景、16物种空目录装载证据；本轮未改主游戏行为，不扩展宣称覆盖。
