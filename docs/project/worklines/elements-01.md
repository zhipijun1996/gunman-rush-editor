# 房间组装与统一目录

本工作线负责主游戏schema3目录的分类消费与实例组装；手机流程、授权、构建及设备验证统一见[编辑器交接](editor-01.md)，不重复维护发行状态。来源为主游戏PR156、编辑器PR2。

主游戏拥有26种行为、127个定义及业务分类。放置入口按library筛选地形、机关、美术表现、怪物与遭遇、NPC与剧情、奖励，隐藏内部服务。工厂、组合引用、信号、运动驱动、宿主及危险附着共用事务校验；移动、复制和删除连同关联元素执行。永久奖励／NPC身份不可直接复制，材质笔刷不改变碰撞。

当前只支持schema3和对应目录，旧草稿不迁移；用户更新前自行导出。定义、参数、端口、状态与外观以主游戏为准，不在编辑器发明行为。旧Demo及旧手机工作台源码入口已在主游戏退役，既有Site与在线数据不在本轮部署范围。

分类逐项匹配游戏目录、机关排除布景／怪物／静态地形、三类放置删除、组合复制与危险／材质浏览器操作已验证。当前完整测试及原生运行包覆盖引用编辑器交接；不把桌面浏览器结果写成Android真机性能。主游戏充电站暂停恢复的既有引擎错误沿主游戏工作线记录，本工作线未通过隐藏错误标绿。
