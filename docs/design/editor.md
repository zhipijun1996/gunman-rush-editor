# 世界编辑器设计

## 职责与数据

编辑器覆盖世界、区域、房间和探索要素。房间布置 JSON 是单一编辑源，Godot 组件／脚本拥有实际行为；正式游戏与预览共享加载器。主游戏导出带 schema、组件目录和内容哈希的版本包，编辑器不得修改包内的行为实现；机关类型与换皮遵守主游戏登记规则，区域美术不同不在编辑器复制底层机关。网页和原生 APK 共用编辑器核心与数据。

所有实例、房间、门口、路线和奖励以稳定 ID 引用。房间位置在空间层世界坐标中定义，实体位置为房间局部坐标。物理地形、镜头范围、逻辑分区及地图展示范围分别保存，不用地图着色修改碰撞。分区、内部有向路线和门对构成同一探索图；能力条件沿游戏 OR-of-AND 语义，能力锁对应实际环境，不生成隐形能力墙。

奖励类型、奖励实例／永久 action 和实际宿主分别持有身份。位置只归宿主；拖动和跨房移动保留领奖身份，复制创建新身份，唯一能力禁止重复。事务同时校验关联宿主、条件和回程要求。

## 地图与操作

所有可放置对象使用主游戏唯一注册目录，界面只保留一个按业务分类筛选的放置入口，内部技术组件隐藏。library声明地形、机关、美术表现、怪物与遭遇、NPC与剧情、奖励等业务归属，category仅作库内分组；分类名称和说明入口来自游戏目录。纯贴图不属于机关库，怪物仍归专门怪物文档和原行为系统；共用实例化能力不改变文档及状态所有权。每种机关定义独立存储，说明集中在主游戏世界对象文档；本编辑器配置实例，不提供另一份库定义权威。房间与项目只支持当前schema3与元素目录，不提供旧草稿转换；用户在更新前自行导出。要素目录由主游戏导出，包含行为参数、外观、输入输出与组合定义。房间编辑支持定义放置、组合实例化、平台尺寸／承载、运动路径、材质与危险笔刷、宿主附着和机关连线。编辑器不执行自定义机关脚本。组合复制重映射内部稳定ID；删除引用、无效端口、即时循环和缺少兼容外观在事务提交前拒绝。撤销重做涵盖整个放置及关联变更。地形碰撞、危险范围和运动轨迹可显示，真实试玩仍交给同版Godot运行包。

世界视图默认展示已校准房间及当前空间草稿的真实占地与连接；尚未空间校准的规划房保留在目录及探索图中，必须显式开启显示，使用虚线并提示临时坐标不能作为整区空间验收。禁止把临时门位推导结果标成已校准世界，不通过移动已审核房间来掩盖规划缺口。房间图标按缩放分级，仅在足够放大时显示门口和奖励细节，避免远景图标遮盖轮廓。缩放到区域显示职责和探索要素，房间细节显示实例与可用的实际场景预览。图像按内容哈希分块缓存，缺少美术时显示灰盒，禁止用示意图冒充真实美术。相同空间层使用统一变换，室内层可切换。

可达分析从明确房间／分区开始，使用用户选择的能力、剧情和机关状态，不自动授予尚未选择的能力。分区级计算有向连通、替代路线和单向返回；可达正常显示、不可达灰色、资料不完整标为未知。无分区轮廓时只标记节点和路线，不伪造精确灰色面积。逻辑分析不等于真实控制器验证。

手机以上方画布、下方操作面板为主界面，分隔条可拖动；面板在 AI、对象编辑、路线及审核之间切换。基础人工操作覆盖点选、移动、尺寸、增删和吸附，复杂编排交给 AI；常用操作和试玩入口不随长属性列表滚走。手机普通点选房间或目录即可进入，不以双击为必要入口；移动房间时保留明显的“进入房间编辑”按钮。房内要素独立放在“元素”页签，点选平台、怪物或机关后直接打开其属性，房间设置与实例操作分开。明确选择实例后定位到便于手指操作的尺度，“整房”恢复房间总览；拖动与改尺寸显式分开，缩小时尺寸手柄不抢移动。保留画布位置、选择、面板比例、任务对话与试玩状态。世界、区域、房间按缩放展示不同细节；查看位置与 AI 写入范围是两个独立状态，导航不会静默扩大权限。

绘制采用 Canvas 2D、视口裁剪和按内容版本缓存，拖动缩放不复制全项目。草稿事务自动持久化，离线恢复包含撤销重做；AI任务具有独立检查点和可查看差异。真实预览一键全屏打开，复用主游戏控制器和原生 Godot；退出恢复原编辑位置，匹配运行包复用驻留引擎。逻辑可达、浏览器操作和真机帧率分别验收，不承诺未经测量的加载速度。

正式导入分别保存真实布置、区域蓝图和仅有拓扑的规划数据及其坐标来源。已有蓝图按其坐标框架展示；未定义空间的房间不以宏观中心乘任意比例或门对遍历推导成真实腔体。规划展示不能冒充正式碰撞。接缝、循环闭合与重叠须报告，不能靠隐藏图层或移动已审核房间掩盖。

## 管理与 AI

开发进度为未开发／开发中／已开发；初审为未初审／初审通过／待复审，与正式接入分开。美术、玩法、世界功能各为0–10整数分，空值表示未评分。AI建议分及依据与用户正式评分分别保存，绑定内容及依赖版本；修改后保留历史并提示复核。AI不得代签人工初审或正式分。

APK使用官方套餐授权路径，系统浏览器完成 PKCE/OIDC，原生安全保存凭据。回调到达、应用注册、凭据交换、身份核验、凭据保存、模型读取及真实请求分别表达；回调收到不能显示 AI 已可用。有效回调先独立保存服务签发的客户端身份，后续失败重试必须复用它，不重复动态注册。回调页及时返回中性接收提示，不让浏览器等待网络核验；身份核验暂不可用时仅在加密区保留本次待核验凭据，重试核验不重用一次性授权码，不把未验证凭据用于AI。启动和返回前台恢复账号与模型，提供重试、退出与取消，重复登录不能排队。取消涵盖监听和正在进行的网络请求；过期回调／迟到响应不得恢复已取消的会话。错误使用明确阶段、固定诊断码、HTTP状态及服务请求ID，不输出完整回调地址、授权码、令牌或原始响应。授权协议对照官方Sign in with ChatGPT DevKit，身份核验使用同一网络客户端与发现的签名密钥地址。验收必须覆盖授权返回后成功执行一次真实编辑，不自动改用收费 API。

AI默认修改当前工作草稿，校验通过的完整事务立即更新画布，不要求逐次采用候选。用户明确要求“另出一版”时生成独立方案供比较、试玩和采用。模型读取最新世界数据，写入范围始终可见；房间、区域、世界范围由用户明确指定。必要门对允许联动直接邻房，但只修改关联端口，不借此改邻房布局，并显示实际影响。范围外大改、主线／能力顺序变动及人工锁定冲突必须提出具体问题，不静默执行。AI不能修改正式评分、初审、锁定或游戏行为目录。

同一任务串行执行有限工具调用，执行中可停止，停止后不再写入。每个成功事务保存差异；任务可整体撤销，并保留之后的人工修改，重叠修改必须报告冲突。流式未完成 JSON 不写草稿；读取基线、依赖、稳定身份、永久奖励收据、权限和锁定统一校验。AI期间仍可查看和编辑，过期结果不能覆盖新内容。聊天只作意图和反馈，当前项目数据是修改事实来源。

## 更新与提交

主游戏组件和素材继续演进。用户更新前自行导出；游戏更新直接用当前版本的数据、目录和匹配运行包替换工作区，清空上一版任务、候选及撤销历史，不迁移或合并旧草稿。应用更新发现随包数据身份或工作区格式变化时重新载入当前随包项目；同版本内重启继续恢复本地编辑。只导入当前格式及兼容当前目录的数据，旧格式明确拒绝，不增加兼容分支。运行资源准备或校验失败不切换；需要原生接口或引擎升级时更新APK。

任务内撤销、AI读取版本检查、锁定和GitHub提交并发检查保留，用于当前编辑与正式提交的正确性，不用于旧草稿兼容。

定稿选择范围并纳入必要门对／奖励依赖，生成来源哈希与明确变更，创建主游戏PR；不擅自合入main。编辑器源码MIT许可，游戏素材和用户草稿不随源码公开。

Android安装包采用兼容的压缩原生库打包，保持同一签名、真实运行资源与离线能力；安装时由系统提取库。发行文件在Release附件保存并核对SHA256，不提交到源码。上传前核对账号、仓库和凭据来源；GH_TOKEN优先于本地CLI登录，独立登录时必须显式选择对应配置。先验证小附件，再上传安装包，核服务器摘要和无需登录的完整下载。上传失败时保留草稿发行及本地产物，明确失败端点，不把失败上传称作发布完成。
